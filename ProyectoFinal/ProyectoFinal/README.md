# The Flavor Lab

Sitio web de un restaurante moderno, creado como proyecto final del curso de Diseño Web (4to A).

**Autor:** Joshua Abraham Vasquez Rodriguez

## Páginas

- **Inicio (`index.html`)**: presentación del restaurante y tarjetas de las categorías del menú.
- **Menú (`menu.html`)**: entradas, platos fuertes, postres y bebidas con sus precios en RD$.

## Estructura de carpetas

```
ProyectoFinal/
├── index.html
├── menu.html
├── CSS/
│   └── style.css      # hoja de estilos única para todo el sitio
└── img/
    ├── hero.svg
    ├── entradas.svg
    ├── platos.svg
    ├── postres.svg
    └── bebidas.svg
```

## Tecnologías

- **HTML5 semántico**: `header`, `nav`, `main`, `section`, `article` y `footer`.
- **CSS3**: Flexbox (navegación y secciones del menú), CSS Grid (tarjetas de inicio) y media queries.

## Diseño

- Paleta: rojo `#BB0A21`, gris `#D3D4D9`, blanco `#FFFFFF` y texto `#252627`.
- Tipografía sin serifas: Gill Sans, Calibri, Trebuchet MS.
- Responsivo: escritorio (más de 768 px), tablet (hasta 768 px) y celular (hasta 480 px).

## Cómo abrirlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en el navegador (o usa la extensión Live Server de VS Code).

No necesita internet: todas las imágenes y estilos están dentro del proyecto.
